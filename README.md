# Brew & Bean — Coffee House

A clean, responsive coffee shop landing page built with **HTML5** and **CSS3**. This is a fictional café concept created as a frontend practice project.

**Live demo:**

## Preview

The page includes a warm coffee-inspired color palette, a CSS-drawn coffee cup illustration, a short café introduction, sample menu cards, and a contact section.

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Semantic HTML structure
- Header navigation with in-page section links
- Hero section with call-to-action link
- About section
- Sample coffee menu with prices
- CSS-only coffee cup illustration
- Hover effects and smooth scrolling
- No external libraries or frameworks required

## Technologies Used

- **HTML5** — page structure and content
- **CSS3** — layout, styling, responsive design, and illustration

## Getting Started

1. Download or clone this project.
2. Extract the ZIP file if you downloaded it.
3. Open the project folder in Visual Studio Code.
4. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code:

1. Install the Live Server extension.
2. Right-click `index.html`.
3. Select **Open with Live Server**.

## Customization

- **Change page content:** Edit the text in `index.html`.
- **Change colors and styles:** Edit the CSS rules in `style.css`.
- **Update menu items:** Find the `.menu-card` elements in `index.html`.
- **Update contact email:** Replace the current `mailto:` address in the Visit Us section with your own email address.
- **Update sample prices and hours:** Replace the demonstration values with accurate information before using this as a real café website.

## Current Limitations

This project is currently a static frontend demonstration.

- There is no JavaScript file or interactive JavaScript functionality.
- There is no backend, database, login, or admin dashboard.
- The menu items, prices, and opening hours are sample content.
- The contact link opens the visitor's default email application; it does not submit a website form.
- There is no online ordering or payment functionality.

## Recommended Improvements

1. Add visible keyboard focus styles for navigation links and buttons.
2. Review accessibility semantics for the CSS coffee illustration.
3. Add a `prefers-reduced-motion` media query for users who prefer less animation.
4. Add a real contact form only when a backend or form service is available.
5. Add JavaScript features such as a mobile navigation toggle or menu filtering if needed.
6. Test the page in multiple browsers and on different screen sizes.
